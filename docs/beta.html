syncdub ベータ版の使い方

ベータ版は、正式版に入れる前の機能を先に試すための試験版です。直したばかりの所が多く、不具合が残っていることがあります。ふつうに使う方は、正式版を使ってください。

  • 正式版とは別のファイル(syncdub_beta.pyw)で、更新も別です。正式版と並べて置けます
  • 合成のあとに、出来上がった動画を自動でチェックします
  • うまくいった結果を記録しておき、新しい版でも同じ結果になるか比べられます
⬇ syncdub_beta.pyw をダウンロード
注意ベータ版で作った動画は、必ず見て・聞いて確かめてください。自動チェックは目安で、すべての不具合を見つけられるわけではありません。

01必要なものと導入

  • 必要なもの(Python と ffmpeg の「full」版)は、正式版と同じです。入れかたは正式版の使い方の「必要なものと導入」を見てください。
  • 上のボタンから syncdub_beta.pyw を保存して、ダブルクリックで起動します。
  • タイトルに「【ベータ版】」、右上に「v〇〇 ベータ12」のように番号が出ていれば、ベータ版です。
ヒントベータ版は、専用のフォルダに置くのがおすすめです。同じフォルダに、バックアップや記録のフォルダができます。正式版の syncdub.pyw と同じフォルダに置いてもかまいません(お互いを上書きしません)。

02正式版とのちがい

画面と基本の使い方は正式版と同じです。ベータ版にだけ、次のものがあります。

機能場所はたらき
映像でも合わせる「かんたん」タブ →「詳細設定」音で合わせたあと、画面の似かたでも合わせて、場所ごとに確かなほうを使います。時間はかかりますが、音だけでは合わない動画に強くなります。
小さなずれの直し(自動)「映像でも合わせる」のとき、区間の中の0.1秒ほどのずれを測り直します。音の途中に無音が入らないよう、つなぎ目を静かな所や場面の変わり目へ移します。
保存先の名前「かんたん」タブ出来上がりの名前を、日本語の録画の名前に合わせます。
自動チェック「かんたん」タブの合成のあと出来上がった動画の日本語音声と英語音声を比べて、おかしそうな所を知らせます。
成功として記録自動チェックのあとに出るボタンうまくいった素材・合わせ方・結果を記録します。
記録と比べる右上の「更新・設定」メニュー記録した素材を今の版でやり直して、結果が変わっていないか比べます(回帰チェック)。
確認ウインドウ「録画から探す」が終わったあと書き出したCMを1本ずつ見比べて、判定を残せます。

03おすすめの手順

「かんたん」タブで1本を合わせるときの流れです。

  1. 英語版の映像と、日本語の録画を入れます。
  2. 「詳細設定」を開いて、「映像でも合わせる」にチェックを入れます。
  3. 「自動で合わせる」を押します。長い動画は10分以上かかることがあります。
  4. 結果の表を見ます。「要確認」の行は、行を選んで先頭を聞き比べます。
  5. 「合成スタート」を押します。終わると、そのまま自動チェックが始まります(バーが動いているあいだはチェック中です)。
  6. 「自動チェック: 問題は見つかりませんでした」と出たら、出来上がった動画を通して見ます。
  7. 問題がなければ、「成功として記録」を押して、メモを1行書きます。
ヒント特に確かめたいのは、音の出入りがある所です。番組の始まりの曲の終わり、CMの前後、場面が暗くなる所、題名が出る所、番組の終わり。
注意前に作った動画をプレーヤーで開いたままだと、同じ名前で上書きできません。合成の前に閉じてください。

04自動チェックの見かた

おかしそうな所があると、報告文の入ったウインドウが開きます。あとから見たいときは「自動チェックの結果」ボタンを押します。時刻は、出来上がった動画の時刻です。

報告意味よくある原因
英語は無音なのに、日本語の音が入っています英語版が無音・暗転の所に、日本語の録画の音が残っています。CMの前後の短い曲や、次の番組の音が入った。
英語は音があるのに、日本語が無音です2秒以上、日本語の音が抜けています。その場面が日本語の録画に見つからなかった。日本語版にない場面のこともあります。
日本語の音が、鳴っている最中に一瞬途切れています音の途中に、短い無音が入っています。英語版だけ少し長い所の「間」が、曲や台詞の途中に入った。
日本語の音が 〇秒 遅れて(早く)入っているようですその6秒間、音の位置がずれているようです。区間の時間差が合っていない。
補足の行について報告文の( )の行は補足です。「ずれを測れた所」は、日本語と英語で同じ曲や効果音が重なっていて、位置を比べられた所の数です。台詞だけの場面は測れません。「1か所だけ外れた測定」「繰り返しのある音で測定があいまいな所」は、測定の外れと見なしたもので、不具合には数えていません。
注意自動チェックに出ない不具合もあります(声だけの場面のずれ、「プツッ」という短い雑音など)。逆に、日本語版だけに台詞がある所などは、問題がなくても報告に出ることがあります。

05おかしい所を見つけたら

  1. 「自動チェックの結果」を開いて、「コピー」を押します。版の番号、合わせ方、区間の一覧まで入っているので、そのまま貼れば状況が伝わります。
  2. 耳で気づいた所は、「何分何秒あたりで、どう聞こえるか」を書き添えます。
  3. その前後20秒ほどを切り出した動画があると、原因を調べやすくなります。出来上がった動画(日本語と英語の音が両方入っています)から切り出すのが基本です。

切り出しの例です。コマンドプロンプトで、動画のあるフォルダに移ってから実行します(10分25秒から20秒間を切り出す例)。

ffmpeg -ss 10:25 -t 20 -i "出来上がり.mkv" -map 0 -vf scale=-2:360 -c:v libx264 -crf 30 -c:a copy "切り出し.mkv"

ヒント日本語の録画の同じ場面も切り出して一緒に送ると、「元の録画ではどうなっているか」まで確かめられます。上の例の入力を日本語の録画に変えて、時刻をその録画での時刻にしてください。

06成功の記録と回帰チェック

ベータ版は直す回数が多いので、「前はうまくいっていた動画が、新しい版でおかしくなっていないか」を確かめるしくみがあります。

記録する

  • 合成と自動チェックが終わり、見て・聞いて問題がなければ、「成功として記録」を押します。
  • メモには、成功と判断した理由を書きます(例: 通して聞いた。始まりの曲と暗転の所も問題なし)。
  • 記録されるのは、素材のファイルの場所、合わせ方、区間の一覧、版の番号、自動チェックの結果、メモです。動画そのものは記録しません。
  • 同じ素材を同じ合わせ方で記録し直すと、前の記録を上書きします。

比べる

  • 右上の「更新・設定」→「記録と比べる (回帰チェック)」を選びます。
  • 記録した素材を、今の版で順に合わせ直します(合成はしません)。1件あたり数分〜10分ほどかかります。
  • 終わると結果が出ます。「コピー」で、そのまま貼れる文面になります。
判定意味どうするか
変化なし区間の一覧も測定も、記録と同じです。何もしなくて大丈夫です。
変化あり・測定は良くなった区間は変わりましたが、ずれや途切れは減っています。改良の結果のことが多いです。気になる所だけ作り直して確かめ、よければ記録し直します。
変化あり・測定は同じ区間は変わりましたが、測定の数字は同じです。変わった区間のあたりを作り直して確かめます。
変化あり・測定が悪くなった(要確認)ずれや途切れが増えています。不具合の可能性が高いので、結果をコピーして報告します。
素材が見つからない記録したときの場所に、動画がありません。動画を元の場所に戻すか、新しい場所で作り直して記録し直します。
いつ比べるかベータ版を更新するたびに行う必要はありません。大きめの直しが入ったあとや、正式版にする前に行うのがおすすめです。記録は、作りの違う素材を数本(CMの入り方が違うもの、音だけでは合いにくいもの、など)そろえておくと役に立ちます。
注意「測定」は、合成せずに元の音から計算した目安です。自動チェックと同じく、耳で分かる不具合をすべて拾えるわけではありません。手で直した結果を記録した場合、比べる相手は自動合わせの結果なので、「変化あり」と出ます。

07更新のしかた

  • 起動時に、新しいベータ版があるか自動で確認します。「新しい版 v〇〇 ベータ13 があります」と出たら、「はい」で更新して再起動します。右上の「更新・設定」→「更新を確認」で、手動でも確認できます。
  • ベータ版の更新は、正式版の更新とは別です。ベータ版を更新しても、正式版は変わりません。
  • 更新すると、前の版は syncdub_beta_backups フォルダに残ります(5つまで)。
  • 新しい版で調子が悪いときは、「更新・設定」→「更新前の版に戻す」で1つ前の版に戻せます。
ヒントベータ版をやめるときは、syncdub_beta.pyw を使わずに、正式版の syncdub.pyw を使うだけです。設定の移しかえは要りません。

08困ったとき

症状対処
「保存先を使えません」と出る同じ名前の動画を、動画プレーヤーなどで開いたままにしています。閉じてからもう一度「合成スタート」を押すか、「変更」で別の名前にします。
「映像でも合わせる」がとても遅い映像を全部読むため、長い動画や高画質の動画では時間がかかります。急ぐときはチェックを外すと、音だけで合わせます。
ファイルを選ぶ画面に、目当ての動画が出てこない選ぶ画面が日付ごとに分かれていて、古い日付のグループに入っていることがあります。一覧の何もない所を右クリックして「グループで表示」を「(なし)」にすると、まとめて並びます。ドラッグ&ドロップでも入れられます。
更新のときに「配布元の記録と一致しません」と出る公開した直後は、数分待つと直ります。しばらく待っても同じときは、このページのボタンから入れ直してください。
自動チェックが終わらない長い動画では1分以上かかります。出来上がった動画は、チェック中でももう開けます。
新しい版にしたら結果がおかしくなった「更新前の版に戻す」で戻して使えます。「記録と比べる」の結果か、自動チェックの報告文を添えて知らせてください。

09ファイルの場所

どれも syncdub_beta.pyw と同じフォルダにできます。

名前中身
syncdub_beta.pywベータ版の本体です。
syncdub_beta_backups フォルダ更新する前の版です(5つまで)。「更新前の版に戻す」で使います。
syncdub_記録 フォルダ「成功として記録」で作った記録です(1素材につき1ファイル)。動画の名前と場所が入るので、人に渡すときは気をつけてください。消すと、その素材は比べる対象から外れます。
ヒント記録のフォルダは、「更新・設定」→「記録のフォルダを開く」で開けます。
