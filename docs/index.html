syncdub 吹き替え音声シンクロツール

TV録画などに入っている日本語吹き替えの音声を、きれいな英語版の映像に合わせて、1本の動画(mkv)にするWindows向けのツールです。映像は再エンコードせず、そのままコピーします。

  • 音の波形を照合して、CMや暗転、カットされた場面を自動で見つけて合わせます
  • うまくいかない所は、波形と画面を見ながら手動で指定(同じ場面・CM・暗転・カット)
  • 出来上がりは、日本語音声が最初(既定)・英語音声も残った mkv
  • ファイルは1つだけ(syncdub.pyw)。更新はGitHub経由で自動
まずはこの3ステップ
  1. 下のボタンから syncdub.pyw を保存して、ダブルクリックで起動
  2. 「かんたん」タブに、英語版の映像と日本語の録画をドロップして「自動で合わせる」
  3. 結果を確認して「合成スタート」
うまくいかないときだけ「手動調整」タブを使います(上級者向け)。ボタンにマウスを乗せると説明が出ます。
syncdub.pyw をダウンロード 最新版を確認中…

01必要なものと導入

必要なもの必須?説明
Python 3必須このソフトを動かすための土台です。python.org から入れます。インストール画面の「Add python.exe to PATH」には必ずチェックを入れてください。tcl/tk のチェックは外さないでください(外すと画面が出ません)。
numpy必須音の計算に使う部品です。コマンドプロンプトで pip install numpy
ffmpeg / ffprobe必須音声・動画を読み書きする道具です。「PATH が通っている」(どのフォルダからでも呼び出せる)状態にします。入れかたは下の「ffmpeg の入れかた」を見てください。コマンドプロンプトで ffmpeg -version と打って、版の情報が出ればOKです。
tkinterdnd2任意入れると、ファイルのドラッグ&ドロップが使えます。pip install tkinterdnd2。入れなくても、クリックでファイルを選べます。

ffmpeg の入れかた(PATH とは?)

PATH は、「どのフォルダにいても、名前を打つだけでそのソフトを呼び出せる」ようにする Windows の設定です。syncdub は ffmpeg を名前で呼び出すので、ここが通っていないと「読み込めない」エラーになります。次のどちらかで入れてください。

かんたんな方法(おすすめ) Windows 10/11 なら、コマンドプロンプト(スタートメニューで「cmd」と検索)に次を貼り付けて Enter。PATH も自動で設定されます。

winget install Gyan.FFmpeg

終わったら、コマンドプロンプトを閉じて開き直し、ffmpeg -version と打って版の情報が出れば完了です。syncdub は一度終了して、起動し直してください。
手動で入れる方法(上でうまくいかないとき)
  1. gyan.dev の ffmpeg ビルドから「release builds」の ffmpeg-release-essentials.zip をダウンロードします。
  2. zip を展開し、中身のフォルダを C:\ffmpeg のような分かりやすい場所に置きます(C:\ffmpeg\bin の中に ffmpeg.exe と ffprobe.exe があれば正解)。
  3. スタートメニューで「環境変数」と検索 →「システム環境変数の編集」→「環境変数」ボタン。
  4. 上の欄(ユーザー環境変数)の Path を選んで「編集」→「新規」で C:\ffmpeg\bin を追加し、OK を押して閉じます。
  5. コマンドプロンプトを開き直して、ffmpeg -version と ffprobe -version で確認します。

困ったときは「Windows PATH 通す」で検索すると、画像つきの解説がたくさん見つかります。

  1. 上の「ダウンロード」ボタンから syncdub.pyw を保存します。
  2. 好きなフォルダに置いて、ダブルクリックで起動します。
ヒント 設定ファイルや旧版のバックアップは、syncdub.pyw と同じフォルダにできます。専用のフォルダに置くのがおすすめです。

02かんたんな使い方

「かんたん」タブで、上から順に4つ進めるだけです。

  1. ファイルを選ぶ … 「英語版の映像」と「日本語の録画」の枠に、ファイルをドロップ(またはクリックして選択)します。読み込みが終わるまで待ちます。
  2. 自動で合わせる … 「自動で合わせる」ボタンを押します。音を照合して、対応する場所を探します(長い動画は数分かかります)。
    ※ ファイルを選んだだけでは始まりません。
  3. 結果を確認 … 区間(A, B, C…)の表が出ます。行を選ぶと、その区間の先頭を聞き比べられます。「要確認」の行は特に確かめてください。
  4. 合成する … 保存先を確かめて「合成スタート」。出来上がると「完成しました」と出ます。

出来上がったファイルの確認

保存先(既定は英語版と同じフォルダの 〜_jpdub.mkv)に、1本の mkv ができます。映像は英語版のまま、音声は日本語(最初・既定)と英語の2本入っています。プレーヤー(VLC など)の「音声」メニューで切り替えられます。「フォルダを開く」ボタンで場所を開けます。

注意 声だけの場面(BGMや効果音が少ない所)は、音の照合が当たりにくく、「要確認」になることがあります。その場合は手動調整で『同じ場面』を足してください。

自動でうまくいかないときや、自分で細かく決めたいときに使う、「手動調整」タブです。上が英語版、下が日本語の録画の波形です。

※ 説明用のイメージ図です

① 同じ場面を登録する

  1. 上(英語)と下(日本語)の波形をクリックして、同じ場面(同じフレーム)にカーソルを置きます。画面は左右のプレビューで確認できます。
  2. 「S この2つは『同じ場面』」を押します。登録した点が音合わせの基準になります。

「A 音で探して合わせる」は、英語側のカーソル付近の音をもとに、日本語側の位置を自動で探して合わせます。「登録するとき、音で微調整する」にチェックすると、登録のたびに数フレーム分を音に合わせて補正します。

② 特別な部分を指定する(波形をドラッグして範囲を選んでから、ボタン)

ボタン選ぶ範囲意味
CM下(日本語)日本語にだけあるCM。使いません
暗転・長さ違い上と下の両方同じ場面だが長さが違う(暗転など)。速さを少し変える / 無音で埋める / 切る、から選びます
カット上(英語)日本語版でカットされた場面。無音にするか、英語版の音を使うか選びます

③ 確認して合成

下の「指定の一覧」で、行をクリックするとその場所に移動します。ダブルクリックで編集、Delete で削除できます。⚠ が出たときは、音の速さが大きく変わる区間があります(暗転などなら「暗転・長さ違い」で指定してください)。最後に「合成スタート」です。

波形の見かた・操作

  • ドラッグ: 範囲を選ぶ / クリック: カーソルを置く
  • マウスホイール・↑↓キー: 拡大縮小(Reaper風。上下は同じ縮尺になります)
  • Shift+ホイール・右ドラッグ: 横にずらす
  • ←→: 1コマ移動(Shift: 1秒、Ctrl: 10コマ)
  • Space・▶再生: カーソル位置から約20秒を再生。もう一度押すと止まります
ヒント 間違えたら Ctrl+Z で戻せます。「設定を保存」で作業内容を json に残せるので、あとで続きから再開できます。

05更新と元に戻す

  • 起動時に新しい版があるか自動で確認します(右上の「起動時に更新を確認」で切り替え)。「更新を確認」ボタンで手動でも確認できます。
  • 更新すると、旧版は syncdub_backups フォルダに残ります(5つまで)。
  • 新しい版で調子が悪いときは、「元に戻す」で1つ前の版に戻せます。

06困ったとき

症状原因と対処
読み込めない・エラーが出るffmpeg / ffprobe が PATH にない可能性があります(「01 必要なもの」の入れかたを参照)。ffmpeg -version を確認してください。
「要確認」が出る声だけの場面などは照合が弱いです。その区間の先頭を聞き比べて、ずれていたら手動調整で『同じ場面』を登録します。
後半に向かって少しずつずれる録画と英語版で速さが微妙に違うことがあります。区間の終わり近くにも『同じ場面』を1つ登録してください。
暗転の長さが違って音が速く/遅くなる「暗転・長さ違い」で、上下の範囲を指定してください(速さを変える / 無音で埋める / 切る)。
再生しても音が出ないffmpeg が必要です。また、Windows の音量・出力先を確認してください。
ドラッグ&ドロップが効かないpip install tkinterdnd2 を実行して、再起動してください。クリックしてファイルを選ぶこともできます。
「区間を判定できませんでした」と出る音が少ない場面や、短い録画(数十秒など)で出ることがあります。最新版に更新して、もう一度「自動で合わせる」を押してください。それでもだめなら、手動調整で『同じ場面』を登録します。
つなぎ目で「プツッ」と音が聞こえる最新版では、つなぎ目の処理を改善しています。更新してから作り直してください。
手動調整の「指定の一覧」が見えない・狭い画面の高さが足りないときに起こります。ウィンドウを縦に広げてください(最新版では見えやすく改善済み)。
ダブルクリックしても起動しないPython が入っていないか、tcl/tk を外してインストールした可能性があります。Python を入れ直してください(上の「必要なもの」参照)。
更新に失敗した・調子が悪い「元に戻す」で前の版に戻せます。
